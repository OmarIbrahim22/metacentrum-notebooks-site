# MetaCentrum Notebooks: executed pages

Static GitHub Pages site showing the
[metacentrum-notebooks](https://github.com/OmarIbrahim22/metacentrum-notebooks)
with their real output, readable without an account or any installation.

**Site:** https://omaribrahim22.github.io/metacentrum-notebooks-site/

This repository holds generated HTML only. Do not edit it by hand; it is
rebuilt by `scripts/site.py` in the showcase kit, which renders the kit's
`executed/` notebooks, labels how each output was produced and checks the
result for credentials and personal details.

To run the notebooks yourself, use the
[e-INFRA BinderHub launcher](https://github.com/OmarIbrahim22/metacentrum-notebooks-binder).
