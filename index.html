MetaCentrum Notebooks

Jupyter notebooks that show how to use MetaCentrum and e-INFRA CZ services from code. Each page is the full notebook with its output, so you can read it without an account, a login or anything installed.

Source repository Run them yourself on e-INFRA BinderHub

00Environment Check & Diagnostics

This notebook confirms your runtime environment (local vs MetaCentrum/e-INFRA), basic tools, GPU presence, Python version, and filesystem paths. Use this as a baseline diagnostic before running other notebooks.

Diagnostics

01S3 Object Storage Integration

Demonstrate authentication and basic operations with CESNET S3 Object Storage using the boto3 SDK. This notebook shows how to list buckets, upload/download objects, generate presigned URLs, and handle common errors.

CESNET S3 storage

02Invenio Repository Integration (EOSC CZ / NRP)

Demonstrate authentication and basic operations with the National Repository Platform (NRP) using the Invenio REST API. This notebook shows how to authenticate, validate access, create draft records, upload files, and handle common API errors.

NRP Data Catch-all Repository

03OpenStack API Integration

Demonstrate authentication and basic operations with OpenStack API using application credentials. This notebook shows how to connect to OpenStack, list compute resources (flavors, images), and understand the platform capabilities.

e-INFRA Cloud (OpenStack)

04Open WebUI Chat API Integration

Demonstrate how to interact with the Open WebUI Chat API (e-INFRA CZ AI service) from a Jupyter notebook. This notebook shows authentication, listing available models, and performing chat completions using the OpenAI-compatible API.

e-INFRA AI Chat

05GPU Container with AI Model

Demonstrate running containers with GPU passthrough to execute AI workloads. This notebook shows how to verify GPU availability, run containers (Apptainer/Singularity), pass GPU devices to containers, and execute AI inference workloads.

Apptainer/Docker with GPU passthrough

06R Kernel Demonstration

Demonstrate using Jupyter with an R kernel instead of Python. This notebook shows how to switch kernels, work with R packages, perform basic data analysis, and create visualizations using R.

R language kernel

07MATLAB Kernel Demonstration

Demonstrate using Jupyter with a MATLAB kernel. This notebook shows how to verify MATLAB availability, switch kernels, perform basic computations, create visualizations, and work with MATLAB-specific features in a Jupyter environment.

How the outputs were produced

Most of these notebooks need credentials for a real service, so their outputs were produced without publishing any account details:

Ran for real
Executed for real on a local machine. Hostname, paths and username are replaced.
Ran for real, once
Executed once for real on suitable hardware. Machine details are replaced.
Replayed recording
The real HTTP traffic was recorded once. The unchanged notebook code then ran again against that recording with placeholder credentials. A request that was never recorded fails, so the output cannot drift from the code.
Recorded on a compatible service
The recording came from a service with the same API instead of the CESNET / e-INFRA one the notebook documents. The notebook page names it.

Outputs are from the notebook version of 2026-10-07 (1f3229a). The repository may have newer changes.
