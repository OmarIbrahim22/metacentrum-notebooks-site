How the outputs were produced

Most of these notebooks need credentials for a real service, so their outputs were produced without publishing any account details.

Ran for real
Executed for real on a local machine. Hostname, paths and username are replaced.
Ran for real, once
Executed once for real on suitable hardware. Machine details are replaced.
Replayed recording
The real HTTP traffic was recorded once. The unchanged notebook code then ran again against that recording with placeholder credentials. A request that was never recorded fails, so the output cannot drift from the code.
Recorded on a compatible service
The recording came from a service with the same API instead of the CESNET / e-INFRA one the notebook documents. The notebook page names it.

Outputs are from the notebook version of 2026-10-07 (1f3229a). The repository may have newer changes.
